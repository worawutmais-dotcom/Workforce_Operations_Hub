# หน้าเช็กอิน: ทางเลือกแผนที่

เป้าหมายคือให้พนักงานตอบได้ในวินาทีเดียวว่า `เช็กอินได้หรือยัง` โดยไม่ต้องตีความวงรัศมี GPS

## 1. แผนที่ยืนยันพื้นที่ — ใช้ใน APK นี้

- แสดงจุดของพนักงานและจุดเช็กอินที่ใกล้ที่สุดเท่านั้น
- เส้นเดียวแสดงความสัมพันธ์ระหว่างสองตำแหน่ง
- แถบสถานะบนแผนที่บอกผลชัดเจน: อยู่ในพื้นที่ / อยู่นอกพื้นที่
- ซูมได้ด้วย pinch หรือแตะสองครั้ง แต่ลากแผนที่ไม่ได้
- เหมาะกับการลงเวลาประจำวัน เพราะอ่านง่ายที่สุด

## 2. บัตรระยะทาง

- ไม่แสดงแผนที่เป็นค่าเริ่มต้น
- ใช้ระยะทาง, ความแม่นยำ GPS และชื่อจุดเช็กอินเป็นบัตรข้อมูลเต็มความกว้าง
- มีปุ่ม `ดูแผนที่` เปิดเฉพาะเมื่อพนักงานต้องการตรวจสอบ
- เหมาะกับเครื่องเน็ตช้าหรือพื้นที่ที่แผนที่ไม่ช่วยตัดสินใจ

## 3. เส้นทางสั้น

- แสดงพนักงาน, จุดเช็กอิน และเส้นตรงระหว่างกันเป็นหลัก
- ระยะทางเป็นตัวเลขใหญ่กลางหน้าจอ พร้อมลูกศรทิศทาง
- ไม่อ้างว่าเป็นเส้นทางเดินจริง จึงไม่ทำให้ผู้ใช้เข้าใจผิด
- เหมาะเมื่อมีหลายจุดและพนักงานอยู่นอกพื้นที่บ่อย

## 4. มุมมองเขตงาน

- ใช้แผนที่ภาพรวมของจุดเช็กอินทุกจุด แต่ไม่แสดงวงรัศมี
- แต่ละจุดเป็นหมุดที่มีชื่อ และเลือกจุดเพื่ออ่านกติกาได้
- ให้ใช้ในแท็บข้อมูลสถานที่ ไม่ใช่หน้าเช็กอินหลัก
- เหมาะกับพนักงานภาคสนามที่ต้องเลือกหน้างานก่อนเริ่มงาน

## การตัดสินใจ

เลือกข้อ 1 สำหรับหน้าแรก เพราะผลลัพธ์และหลักฐานตำแหน่งอยู่ในจอเดียวโดยไม่มีองค์ประกอบเทคนิคเกินจำเป็น. ข้อ 2–4 ควรเป็นทางเลือกตามรูปแบบงาน ไม่ใช่ตัวสลับที่ทำให้พนักงานต้องคิดทุกวัน.
