# AI Collaboration Brief — Workforce Operations Hub

## Product scope

BVN Package internal workforce system: employee mobile attendance, Windows Python Admin, Google Sheets audit datastore, and headless Google Apps Script mobile gateway. It is not yet a legally complete payroll/accounting system.

## 2026-11-19 — BVN control-room visual direction

- Dashboard now uses BVN's own operations-console treatment: graphite/ink navigation, neutral work canvas, and four semantic summary tiles for recorded attendance, not-yet-checked-in staff, attendance exceptions, and payroll-slip readiness. The colour is functional rather than decorative, and every tile links to the matching work queue.
- This is deliberately inspired by conventional back-office information hierarchy only; it does not reuse the reference application's branding, icons, content, or layout.

## ⚠️ Build workflow — admin console (read before editing)

`admin_codex/index.html` is now a **BUILD ARTIFACT**, not a source file. **Do NOT hand-edit it.**
Edit the split sources instead, then rebuild:

- `admin_codex/src/app.css` — the `<style>` contents (console stylesheet)
- `admin_codex/src/app.js` — the `<script>` contents (all console JS)
- `admin_codex/src/index.template.html` — the HTML shell (CSS/JS go into its `/*__BVN_APP_CSS__*/` and `/*__BVN_APP_JS__*/` markers)

After editing any src file: **`node tools/build_admin.mjs`** → regenerates `admin_codex/index.html`.
`node tools/admin_build_fresh_test.mjs` fails if `index.html` drifts from `src/` (run it before committing, with the other `tools/*_test.mjs`). The deployed artifact is still the single `admin_codex/index.html` — publishing/hosting is unchanged.

Pre-commit test set (all run by `npm test`, and by GitHub Actions `.github/workflows/ci.yml` on every push/PR): `admin_build_fresh_test` · `mirror_sync_test` · admin JS parse · `admin_redesign_contract_test` · `payroll_period_policy_test` · `shortfall_policy_test` · `late_absence_policy_test` · `ot_multiplier_test`. Build the console with `npm run build` (= `node tools/build_admin.mjs`).

## Decisions

- Admin and back-office exist only in the Windows Python desktop application.
- Google Sheets is the temporary datastore/audit trail; it is not an Admin UI.
- Apps Script is a headless mobile API; server validation must remain authoritative.
- BVN Package site: `13.762962071350593, 100.5582875856417`; permitted radius 150 m; GPS accuracy limit 100 m.
