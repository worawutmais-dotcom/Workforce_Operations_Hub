# Employee Account Compact Release — 1.0.16+16

วันที่เผยแพร่: 26 พฤศจิกายน 2569  
สถานะ: เผยแพร่ APK และตั้งค่าอัปเดตในระบบแล้ว

## เป้าหมาย

ทำให้หน้า **บัญชี / Profile** ของแอปพนักงานใช้งานจบในหน้าจอเดียวบนมือถือขนาดมาตรฐาน โดยลดข้อมูลและคำขอที่ไม่จำเป็นออกจากเส้นทางหลัก

## สิ่งที่เปลี่ยน

### เอาออกจากฝั่งแอปพนักงาน

- ปุ่มและ dialog `ขอเบิกเงินล่วงหน้า` ในหน้า Account
- รายการและตัวกรอง `เงินล่วงหน้า` ในหน้า คำขอของฉัน
- การเรียกข้อมูลเงินล่วงหน้าขณะเปิดหน้าคำขอ

การเปลี่ยนแปลงนี้ **ไม่ลบข้อมูลเบิกเงินเดิมในฐานข้อมูล** และไม่เปลี่ยน workflow การเงินของผู้ดูแลระบบ

### หน้า Account ใหม่

หน้า Account ใช้ compact layout แบบไม่ต้องเลื่อนบนพื้นที่ทดสอบ 360 × 800 px โดยมีเฉพาะข้อมูลและการกระทำที่จำเป็น:

1. ชื่อ, ตำแหน่ง และรหัสพนักงาน
2. สถานะบัญชี และสถานะข้อมูลส่วนตัว
3. นโยบายการลงเวลาตามพิกัด
4. ยืนยัน/แก้ไขข้อมูลส่วนตัว
5. เปลี่ยนรหัสผ่าน หรือขอรีเซ็ตรหัสผ่าน
6. ออกจากระบบ และหมายเลขเวอร์ชันแอป

กรณีข้อมูลส่วนตัวยังไม่ครบ ระบบยังแสดงแถบแจ้งเตือนที่กดเพื่อกรอกข้อมูลได้ โดยย่อข้อความให้ไม่ดันส่วนสำคัญออกนอกหน้าจอ

## UAT ที่แนะนำ

1. ติดตั้ง APK 1.0.16+16 ทับแอปเดิม
2. เปิดแท็บบัญชีบนอุปกรณ์ Android จริง
3. ยืนยันว่าเห็นข้อมูลครบโดยไม่ต้องเลื่อนบนหน้าจอขนาดใช้งานจริง
4. กดข้อมูลส่วนตัว, เปลี่ยนรหัสผ่าน และรีเซ็ตรหัสผ่านเพื่อตรวจ navigation
5. เปิดหน้าคำขอและยืนยันว่าแสดงเฉพาะคำขอลา

## ขอบเขตที่ยังคงอยู่

- API เกี่ยวกับเงินล่วงหน้าและข้อมูลเดิมยังอยู่ เพื่อไม่กระทบ admin/payroll ที่มีอยู่
- หากต้องการยกเลิก feature เงินล่วงหน้าทั้งระบบ ต้องแยกงานทบทวนผลกระทบกับ payroll, ฐานข้อมูล และรายงานก่อน
